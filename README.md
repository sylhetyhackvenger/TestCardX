🚀 QUICK START GUIDE

1. Installation

```bash
# Clone repository
git clone https://github.com/Sylhetyhackvenger/TestCardX 

# Navigate to directory
cd TestCardx 

# Set permissions
chmod +x testcardx.py
```

2. Basic Commands

```bash
# Start interactive TUI
./testcardx.py

# Generate test cards
./testcardx.py --generate 50 --country USA

# Validate a card
./testcardx.py --validate "4111111111111111"

# Batch generation with export
./testcardx.py --batch 1000 --country INDIA --export json --output indian_cards
```
